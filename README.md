# Giving365 Agent

- A web-based chatbot client that connects to **Microsoft Copilot Studio / Power Virtual Agents** using the **Direct Line API**.  
- The Giving365 Agent is a custom Copilot chatbot designed to support church leaders and staff in improving their fundraising strategies.
- Built with a user-friendly conversational flow, the bot provides tailored guidance on fundraising topics such as annual campaigns, capital campaigns, special giving, and planned giving.
